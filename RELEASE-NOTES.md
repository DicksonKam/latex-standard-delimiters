Beta release: render standard LaTeX delimiters in Reading View and Live Preview, with source coloring and previews while editing. Markdown source is preserved.

Verified on Obsidian 1.13.7 for macOS: 19 unit tests and 195 actual-app checks. Extended MathJax 0.4.1 shared macros/load orders were checked. Real mobile and OS IME verification remain outstanding. SwiftLaTeX coexistence was checked without full PDF/SVG compilation. See VERIFICATION.md and COMPATIBILITY.md.

Install through BRAT using DicksonKam/latex-standard-delimiters, or place main.js, manifest.json, and styles.css together in .obsidian/plugins/latex-standard-delimiters/ and enable the plugin. Keep data.json when updating.
