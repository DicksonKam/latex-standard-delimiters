0.4.4 fixes multiline list displays disappearing when punctuation or prose follows the closing delimiter. Valid blank rows inside list math are accepted, and Reading View now renders displays split into separate paragraphs by blank rows. Cross-section rendering is bound to exact source sections, with per-text-fragment restoration preserving paragraph structure when the plugin unloads. Note source remains unchanged.

The new boundary suite exercises 31 layouts twice in both views, including ordered/nested/task/quoted lists, adjacent and identical equations, literal lookalikes, Unicode and blank rows, plus active preview identity and unload restoration. It is required by release packaging alongside the original runtime/stress and native keyboard evidence. See VERIFICATION.md for counts and tested limits.

Desktop GitHub/BRAT beta, tested on macOS/Obsidian 1.13.7. Update through BRAT using DicksonKam/latex-standard-delimiters, or replace main.js, manifest.json and styles.css together while preserving data.json. MIT license and upstream attribution are included.
