0.4.3 fixes two everyday rendering defects. Multiline standard-delimiter displays beside prose, punctuation or indentation now render in Live Preview. Active callout previews no longer show Markdown quote markers as greater-than signs when valid multiline equations share a line with prose or punctuation. Source, surrounding text, container prefixes and line breaks remain intact; inconsistent container boundaries still fail closed.

New daily editing tests verify displayed numeric identities after edits/undo, delimiter recovery, moving equations between structures, folded-state transitions, repeated vertical entry and same-note pane updates. Native UI checks cover Down/Right, typing, undo/redo, Backspace and exact LaTeX paste, with trusted event evidence. Both are required by release packaging alongside existing runtime/stress evidence. Full verification counts and limits are recorded in VERIFICATION.md.

Desktop GitHub/BRAT beta, tested on macOS/Obsidian 1.13.7. Update through BRAT using DicksonKam/latex-standard-delimiters, or replace main.js, manifest.json and styles.css from this release while preserving data.json. MIT license and upstream attribution remain included.
